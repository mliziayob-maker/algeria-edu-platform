# منصة أكاديمية أمين الذكية 🎓

## الرؤية
منصة تعليمية جزائرية مفتوحة المصدر، تستخدم الذكاء الاصطناعي لتقديم تعليم مخصص ومتفاعل لجميع الأطوار (ابتدائي، متوسط، ثانوي).

## الميزات الرئيسية
- 🤖 **أستاذ افتراضي ذكي** (يعتمد على Gemini API).
- 📝 **تمارين تفاعلية** مع تصحيح فوري وتغذية راجعة.
- 📊 **تتبع التقدم الشخصي** وتحليلات التعلم.
- 🌐 **متعدد اللغات** (عربية، إنجليزية، فرنسية).
- 🎮 **نظام تحفيزي** (نقاط، شارات، ومتسلسلات تعلم).
